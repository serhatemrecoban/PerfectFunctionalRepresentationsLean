PerfectFunctionalRepresentations.Primal.feasible_reindex_iff

Independent finite row and column presentations preserve primal feasibility,
with pointwise inequalities and inverse coordinate transport.
∀ {α : Type u} [inst : Fintype.{u} α] [inst_1 : Nonempty.{u + 1} α]
  (D : PerfectFunctionalRepresentations.CompressedPatternData.{u} α)
  (x : PerfectFunctionalRepresentations.Incidence.AdmissiblePartition.{u} D → ℝ) {m n : ℕ}
  (rows : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.OccurringPattern.{u} D) (Fin m))
  (cols : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.AdmissiblePartition.{u} D) (Fin n)),
  PerfectFunctionalRepresentations.Primal.Feasible.{u} D x ↔
    (∀ (j : Fin n), LE.le.{0} 0 (Function.comp.{1, u + 1, 1} x (⇑(Equiv.symm.{u + 1, 1} cols)) j)) ∧
      ∀ (i : Fin m),
        LE.le.{0}
          (Matrix.mulVec.{0, 0, 0}
            ((Matrix.reindex.{0, 0, u, u, 0} rows cols)
              (PerfectFunctionalRepresentations.Incidence.reducedMatrix.{u} D))
            (Function.comp.{1, u + 1, 1} x ⇑(Equiv.symm.{u + 1, 1} cols)) i)
          (Function.comp.{1, u + 1, 1} (PerfectFunctionalRepresentations.CompressedPatternData.value.{u} D)
            (⇑(Equiv.symm.{u + 1, 1} rows)) i)

PerfectFunctionalRepresentations.Primal.objectiveValues_reindex

The entire finite-coordinate objective image equals the intrinsic image.
The inverse vector map covers every finite vector, including empty columns.

  (cols : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.AdmissiblePartition.{u} D) (Fin n)),
  Eq.{1}
    (Set.image.{0, 0} (fun z => ∑ j, z j)
      (Set.ofPred.{0} fun z =>

          ∀ (i : Fin m),
            LE.le.{0}
