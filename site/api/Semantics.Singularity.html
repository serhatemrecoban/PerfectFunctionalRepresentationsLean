PerfectFunctionalRepresentations.coordinate_eq_of_posterior_support

Under a common-posterior factorization, each supported posterior vector has
coordinate `y` at every input whose row can emit `y`. Reused by the direct
nonrepresentability example; no finite-alphabet assumption is needed.
∀ {alpha : Type u} {beta : Type v} (q : PMF.{max u v} (alpha → beta)) (kappa : alpha → PMF.{v} beta)
  (V : beta → PMF.{max u v} (alpha → beta)),
  (∀ (x : alpha),
      Eq.{max (u + 1) (v + 1)} (PMF.map.{max u v, max u v} (fun w => Prod.mk.{v, max u v} (w x) w) q)
        (PMF.channelJoint.{v, max u v} (kappa x) V)) →
    ∀ {x : alpha} {y : beta} {w : alpha → beta},
      Ne.{1} ((kappa x) y) 0 →
        Membership.mem.{max u v, max u v} (PMF.support.{max u v} (V y)) w → Eq.{v + 1} (w x) y

PerfectFunctionalRepresentations.isSingularChannel_map_iff

Adding output symbols through an injection preserves intrinsic singularity.
Columns outside the image have zero mass in every row.
∀ {alpha : Type u} {beta : Type v} {gamma : Type v'} [Finite.{u + 1} alpha] [Finite.{v + 1} beta]
  [Finite.{v' + 1} gamma] (kappa : alpha → PMF.{v} beta) (j : beta → gamma),
  Function.Injective.{v + 1, v' + 1} j →
    ((PerfectFunctionalRepresentations.IsSingularChannel.{u, v'} fun x => PMF.map.{v, v'} j (kappa x)) ↔
      PerfectFunctionalRepresentations.IsSingularChannel.{u, v} kappa)

PerfectFunctionalRepresentations.isPerfectlyRepresentableChannel_map_iff

Injective output extension preserves the complete common-posterior witness.
In either direction both components of each coordinate/vector joint law are

PerfectFunctionalRepresentations.isSingularChannel_relabel_iff

Finite input/output relabeling uses the inverse input equivalence and the
forward output equivalence. Either equivalence may be the identity.

  [Finite.{u' + 1} alpha'] [Finite.{v + 1} beta] [Finite.{v' + 1} beta'] (kappa : alpha → PMF.{v} beta)

    PerfectFunctionalRepresentations.IsSingularChannel.{u, v} kappa

PerfectFunctionalRepresentations.isPerfectlyRepresentableChannel_iff_isSingular_of_activeOutputs_card_le_two

Singularity is equivalent to perfect representability when the union of all
row supports contains at most two outputs. The active subtype's enumeration is internal;
globally unused ambient outputs impose no additional hypothesis.
∀ {alpha : Type u} {beta : Type v} [Fintype.{u} alpha] [inst : Fintype.{v} beta]
  [inst_1 : Nonempty.{u + 1} alpha] (kappa : alpha → PMF.{v} beta),
  have this := Fintype.ofFinite.{v} ↑(PerfectFunctionalRepresentations.activeOutputs.{u, v} kappa);
  LE.le.{0} (Fintype.card.{v} ↑(PerfectFunctionalRepresentations.activeOutputs.{u, v} kappa)) 2 →
    (PerfectFunctionalRepresentations.IsPerfectlyRepresentableChannel.{u, v} kappa ↔
      PerfectFunctionalRepresentations.IsSingularChannel.{u, v} kappa)
