PerfectFunctionalRepresentations.partitionOfBlocks

Construct an exact partition from a finite labelled family of nonempty,
pairwise disjoint blocks with exactly the prescribed carrier.
{alpha : Type u} →
  {I : Type v} →
    [Finite.{v + 1} I] →
      (s : Finset.{u} alpha) →
        (blocks : I → Finset.{u} alpha) →
          (∀ (i : I), Finset.Nonempty.{u} (blocks i)) →
            (Pairwise.{v} fun i j => Disjoint.{u} (blocks i) (blocks j)) →
              (∀ (x : alpha), Membership.mem.{u, u} s x ↔ ∃ i, Membership.mem.{u, u} (blocks i) x) →
                Finpartition.{u} s

PerfectFunctionalRepresentations.partitionOfBlocksEquiv

Every supplied label corresponds to exactly its original block. The
nonempty-disjoint hypotheses rule out two labels for the same block.
{alpha : Type u} →
  {I : Type v} →
    [inst : Finite.{v + 1} I] →
      (s : Finset.{u} alpha) →
        (blocks : I → Finset.{u} alpha) →
          (hne : ∀ (i : I), Finset.Nonempty.{u} (blocks i)) →
            (hdis : Pairwise.{v} fun i j => Disjoint.{u} (blocks i) (blocks j)) →
              (hcover : ∀ (x : alpha), Membership.mem.{u, u} s x ↔ ∃ i, Membership.mem.{u, u} (blocks i) x) →
                Equiv.{v + 1, u + 1} I
                  ↥(Finpartition.parts.{u}
                      (PerfectFunctionalRepresentations.partitionOfBlocks.{u, v} s blocks hne hdis hcover))
