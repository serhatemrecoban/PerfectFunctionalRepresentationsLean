Transpose multiplication transports a dual vector through independent finite
presentations; transposition swaps the row and column equivalences.
∀ {α : Type u} [inst : Fintype.{u} α] [inst_1 : Nonempty.{u + 1} α]
  (D : PerfectFunctionalRepresentations.CompressedPatternData.{u} α)

  (rows : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.OccurringPattern.{u} D) (Fin m))

with the inverse vector transport covering every finite vector.

  (D : PerfectFunctionalRepresentations.CompressedPatternData.{u} α)

  (rows : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.OccurringPattern.{u} D) (Fin m))
  (cols : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.AdmissiblePartition.{u} D) (Fin n)),
  PerfectFunctionalRepresentations.Dual.Feasible.{u} D y ↔
    (∀ (i : Fin m), LE.le.{0} 0 (Function.comp.{1, u + 1, 1} y (⇑(Equiv.symm.{u + 1, 1} rows)) i)) ∧

PerfectFunctionalRepresentations.Dual.objectiveValues_reindex

The entire finite-coordinate attained objective image equals the intrinsic
image. The inverse vector `z ∘ rows` covers every finite vector, including when
the partition presentation has no coordinates.
∀ {α : Type u} [inst : Fintype.{u} α] [inst_1 : Nonempty.{u + 1} α]
  (D : PerfectFunctionalRepresentations.CompressedPatternData.{u} α) {m n : ℕ}
  (rows : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.OccurringPattern.{u} D) (Fin m))
  (cols : Equiv.{u + 1, 1} (PerfectFunctionalRepresentations.Incidence.AdmissiblePartition.{u} D) (Fin n)),
  Eq.{1}
    (Set.image.{0, 0}
      (fun z =>
        dotProduct.{0, 0}
          (Function.comp.{1, u + 1, 1} (PerfectFunctionalRepresentations.CompressedPatternData.value.{u} D)
            ⇑(Equiv.symm.{u + 1, 1} rows))
          z)
      (Set.ofPred.{0} fun z =>
        (∀ (i : Fin m), LE.le.{0} 0 (z i)) ∧
          ∀ (j : Fin n),
            LE.le.{0} 1
              (Matrix.mulVec.{0, 0, 0}
                (Matrix.transpose.{0, 0, 0}
                  ((Matrix.reindex.{0, 0, u, u, 0} rows cols)
                    (PerfectFunctionalRepresentations.Incidence.reducedMatrix.{u} D)))
                z j)))
    (PerfectFunctionalRepresentations.Dual.objectiveValues.{u} D)
