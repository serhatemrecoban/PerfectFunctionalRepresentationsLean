### S04 certificate and S05 interface

`Matrix.OperationFactorization` holds the private certificate machinery and is
imported by `Matrix.OperationCalculus`. The existing local interchange module
already has 2417 lines; this split keeps the two different proof arguments
separately inspectable without changing the semantic root.

The core uses pinned `BinaryTree`, a finite dependent leaf carrier, positive
NNReal branch products, Boolean support trees and exact routed-row sums.
For a sheet of source column `i`, leaf `f` has support precisely
`S.channel x i ≠ 0 ∧ route x = f`. Its assigned endpoint has the same support.
This gives disjointness, coverage and legal nonempty internal support splits.
Pointwise fragment coordinates are derived using the existing admitted
singular-column values.

Two private organization refinements preserve the full S04 mathematical
contract. First, PPS adds the given strict ratio at each outer root and copies
every old sheet, including sheets without the selected endpoint. Both copies
of every unselected fragment compensate to its original mass. This uniform
construction uses a larger finite forest than selective duplication, but
removes conditional dependent carriers; no operation-count bound is required.
Second, gathering trees are constructed from each finite nonempty endpoint
fiber, with explicit leaf equivalences and their exhaustive global bijection.
Their shapes need not retain the history of earlier gathering trees. This
preserves actual finite binary trees, positive equal-support leaves and exact
root coordinates; it assumes no operation path or normalization result.
The fibers use the fragment assignment already established by the split
forest; they do not posit a new arbitrary support partition. The bound reviewer
independently assessed both choices against the required certificate outcomes;
the original report and reconciliation are recorded below. The registered
normative plan is unchanged.
